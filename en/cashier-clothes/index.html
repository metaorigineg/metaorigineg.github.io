Installation steps

  1. 1Download the program from «Direct download» or any server above and extract it (it is a RAR file — open it with WinRAR or 7-Zip).
  2. 2If Windows shows «Windows protected your PC», click More info → Run anyway (this is normal for any new program not from the Microsoft Store).
  3. 3Run «Meta Origin - Cashier Clothes Setup.exe» and choose: the main PC (the one that holds the data) or another device on the network.
  4. 4Choose «14-day trial» or enter your license — the machine code appears in the setup wizard if you want to activate.
  5. 5Open the program, sign in, and start from the detailed guide inside it — or contact us and we will help.

System requirements

  • Windows 10 or 11 (64-bit)
  • 4 GB RAM or more (8 GB for the main PC on a large network)
  • At least 1 GB of free disk space
  • Network: devices on the same router/network as the main PC
  • Works with thermal and A4 invoice printers and barcode readers
