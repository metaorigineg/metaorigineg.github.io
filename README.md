# Meta Origin — الموقع (metaorigineg.github.io)

صفحة الشركة + صفحة تحميل لكل برنامج. كل البيانات في `programs.json` (البرامج، الوصف، الألوان، المميزات، روابط التحميل، فريق العمل).

- تعديل: عدّل `programs.json` ← `node build.mjs` ← بيكتب `index.html` و`<slug>/index.html`.
- برنامج من غير `downloads` بيظهر «قريبًا» وزرار «اطلب البرنامج على الواتساب».
- الأيقونات في `icons/<slug>.png` (من `server logo.png` بتاع كل برنامج)، والصور في `img/`.

## اللغتين (2026-10-28)
- العربي في الجذر والإنجليزي تحت `/en/` — نفس الصفحات، وزرار «English / عربي» فوق في كل صفحة بيوديك لنفس الصفحة باللغة التانية.
- نصوص الإنجليزي للبرامج والشركة والفريق والتصنيفات وشارات التحميل في `programs.en.json` (أي حاجة ناقصة بتظهر بالعربي)،
  ونصوص الصفحات نفسها في `build.mjs` بـ `L('عربي', 'English')`. **برنامج جديد = ضيف له مفتاح في programs.en.json كمان.**
- برنامج مخفي مؤقتًا: `"hidden": true` في programs.json (مالوش كارت ولا صفحة في اللغتين). مخفي دلوقتي: Cashier Clothes و HR و HR Enterprise.

## إضافات الموقع (2026-10-28)
- **«إيه البرنامج المناسب ليك؟»** في الرئيسية: نوع النشاط ← البرامج المناسبة (`PICKER` في build.mjs، الأول = الأنسب؛ المخفي بيتشال لوحده).
- **«آخر التحديثات»** (`/updates/` و `/en/updates/`): أحدث إصدار لكل برنامج (الإصدارات اللي نزلت نفس اليوم بنفس الملاحظات في كارت واحد)
  + سجل كل الإصدارات. المصدر `tools/shared/whats-new/whats-new.js` (+ changelog.py بتاع HR) ← بيتحفظ في `updates.json`.
- **عدد مرات التحميل** من GitHub Releases ← `downloads.json` (بيظهر بس لما البرنامج يعدّي 10 تحميلات — `DL_MIN`).
- **أسئلة خاصة بكل برنامج** في `faq.json` (عربي + إنجليزي، من وصف ومميزات البرنامج بس) قبل الأسئلة العامة.
- **جوجل والمشاركة**: canonical + og/twitter + بيانات منظمة (SoftwareApplication + FAQPage لكل برنامج، Organization + WebSite للرئيسية).
  صورة المشاركة لكل برنامج `img/og/<slug>.jpg` من صور الدعاية: `python og-images.py` (بعد `tools/promo/make-promo.mjs`). Sales ERP لسه مالوش صورة دعاية (بياخد الأيقونة).
  ⚠ ماتحطش سعر (offers) في البيانات المنظمة غير لما يبقى فيه سعر حقيقي — السعر صفر جوجل هيكتبه «مجاني».
- `collect-releases.mjs`: التاريخ باليوم المحلي (كان بتوقيت جرينتش فالبناء بعد 12 بالليل كان بيطلع امبارح).
